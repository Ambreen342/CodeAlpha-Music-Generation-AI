# CodeAlpha Music Generation AI

An AI-based music generation project developed during my CodeAlpha Artificial Intelligence Internship.

## Features

- AI-generated music
- Mood-based music generation
- Tempo selection
- MIDI generation
- WAV audio generation

## Technologies

- Python
- TensorFlow/Keras
- MIDI processing
- Machine Learning

## Project Files

- `app.py` - application interface
- `train_model.py` - model training
- `preprocess.py` - data preprocessing
- `generate_music.py` - music generation
- `create_midi.py` - MIDI creation
- `midi_to_wav.py` - audio conversion

## Internship

Developed as part of the CodeAlpha Artificial Intelligence Internship.
